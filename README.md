# 🎓 Student Skill & Internship Readiness Analyzer

A Streamlit application that analyzes student skills, identifies skill gaps, and measures internship readiness based on their target career.

## 🚀 Live Demo

https://student-skill-analyzer.streamlit.app

## ✨ Features

- 👤 Student profile selection
- 🎯 Target career selection
- 🛠️ Current skill selection
- 📊 Internship readiness score
- ✅ Shows skills you already have
- 📚 Shows skills you should develop
- 💡 Helps students understand what to learn next

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- CSV

## ⚙️ How It Works

1. Enter your student details.
2. Select your department and year.
3. Select your target career.
4. Select your current skills.
5. The app compares your skills with the skills required for that career.
6. The app displays your internship readiness and skill gaps.

## 📁 Project Structure

- `app.py` — Main Streamlit application
- `careers.csv` — Career and skill data
- `requirements.txt` — Required Python packages
- `README.md` — Project documentation

## 🎯 Purpose

This project helps students understand their current skills and identify the skills they need to develop for their desired career or internship.
